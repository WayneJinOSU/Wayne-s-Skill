# Dynamic PEG + Compound PEG + Forward PE Workflow

用于正式成长股估值。最终区间必须由三套方法交叉支持，不允许单一 PEG 直接定价。

## 1. Output Mode

| 模式 | 条件 | 输出 |
| --- | --- | --- |
| `consensus_mode` | 一致预期可用，自有正常/乐观利润锚完整 | 三锚估值、目标市值、隐含预期、情景迁移 |
| `no_consensus_mode` | fallback 后仍无一致预期，但自有锚完整 | 自有情景三锚估值、隐含预期、触发与证伪 |
| `preparation_only` | 利润锚、增速或 Forward PE 参照缺失 | 关键缺口；不得输出正式目标市值 |

## 2. Required Fields

| 字段 | 用途 |
| --- | --- |
| `valuation_date`、`forecast_vintage` | 固定估值与预测版本 |
| `current_market_cap`、`current_price`、`shares_outstanding` | Forward PE、目标价、隐含预期 |
| `consensus_profit_2026E/2027E/2028E` | 市场对照 |
| `own_normal_profit_2026E/2027E/2028E` | 正常利润锚 |
| `own_bull_profit_2026E/2027E/2028E` | 乐观利润锚 |
| `actual_profit_latest_year` | 最近实际年度利润，防止盈利跃迁从估值判断中消失 |
| `profit_yoy_2026E/2027E/2028E` | 完整逐年客观增速 |
| `profit_cagr_actual_to_main_year`、`profit_cagr_current_forecast_to_far_year` | 历史—预测复合增速与前瞻持续增速 |
| `valuation_growth_dynamic`、`valuation_growth_compound` | 模型裁量后用于PEG的估值增速 |
| `peg_coefficient_normal/bull` | PEG系数及选档依据 |
| `forward_pe_normal_range`、`forward_pe_bull_range` | 绝对倍数锚 |
| `forward_pe_evidence` | 公司历史、可比公司、商业质量与周期位置 |
| `profit_quality_note` | 非经常、少数股东、投资收益、现金流与营运资本 |
| `source_notes` | 数据来源与日期 |

缺少可解释的 Forward PE 区间时，只能输出试算，不得称为正式三锚估值。

## 3. Growth Panorama and Valuation Growth

先展示完整利润路径。估值时点为2026年时，至少计算：

```text
2025A -> 2026E同比
2026E -> 2027E同比
2027E -> 2028E同比
2025A -> 2027E CAGR
2026E -> 2028E CAGR
```

五组数字各有用途：

| 增速 | 用途 |
| --- | --- |
| 最近实际年→当前预测年 | 判断盈利跃迁是否真实、是否存在低基数和一次性因素 |
| 当前预测年→主估值年 | 动态PEG的核心前瞻输入 |
| 主估值年→远期年 | 判断增速是否快速衰减 |
| 实际年→主估值年CAGR | 衡量整轮盈利跃迁强度 |
| 当前预测年→远期年CAGR | 衡量未来增长持续性 |

### Model-Judged Valuation Growth

正式报告同时输出“客观增速”和“估值增速”。估值增速由模型综合上述五组数字裁量，不使用固定加权公式。

```text
估值增速 ≠ 任一客观增速的机械复制
```

判断原则：

- 最近实际年到当前预测年的高增已经大部分兑现，不应全额抬高远期PE；但若财报、扣非和现金流证明结构性跃迁，可使估值增速高于纯前瞻CAGR。
- 未来逐年降速明显、低基数强或周期属性重时，估值增速应向前瞻CAGR收敛。
- 连续财务兑现、增长底座永久抬升、远期增速仍高时，可在纯前瞻增速之上保留部分历史跃迁。
- 每个情景必须给出估值增速区间、相对各客观增速的位置和理由；不得只报最终数字。

例如某成长周期的客观增速为：实际年→当前预测年约86%、当前预测年→主估值年约37%、当前预测年→远期年CAGR约33%、实际年→主估值年CAGR约60%。模型可基于已兑现程度与持续性，将正常估值增速裁量为约42%–46%，但这只是示例，不是通用固定区间。

## 4. PEG Coefficient Selection

PEG系数单独反映增长质量，不等同于增长率本身：

| PEG档位 | 典型状态 |
| ---: | --- |
| 0.6–0.8 | 周期性强、低基数明显、现金流弱或增长可能快速回落 |
| 0.8–1.0 | 增长已验证，但持续性、顺价或利润质量仍不完整 |
| 1.0 | 增长质量和持续性达到基准合理状态 |
| 1.1–1.2 | 高质量成长、竞争壁垒增强、现金流与远期能见度较高 |
| >1.2 | 稀缺性或趋势溢价，必须标注高风险且不作为普通中枢 |

正式估值必须：

1. 分别为正常、乐观情景选择PEG区间并说明证据。
2. 至少展示PEG=0.9、1.0、1.1的敏感性结果；它是透明度检查，不代表三档都合理。
3. PEG=1.1不得仅因利润增速高；需要独立证据证明增长持续性、现金流、份额或壁垒改善。
4. 若估值增速已高于纯前瞻增速以纳入历史盈利跃迁，PEG系数原则上应更靠近0.9–1.0；除非存在不重叠的质量证据，不能同时无折扣采用高估值增速与1.1以上PEG。
5. 不得根据当前股价、市值或想要得到的目标区间反推PEG系数。

## 5. Three Independent Anchors

### Dynamic PEG

```text
动态估值增速 = 模型参考主估值年度同比及完整增长路径后裁量的增速（百分数）
动态 PEG 对应 PE = 动态 PEG 系数 × 动态增速
动态 PEG 市值 = 主估值年度利润锚 × 对应 PE
```

它捕捉近期利润加速，但容易受单年低基数和周期峰值影响。

### Compound PEG

```text
复合估值增速 = 模型参考实际年→主估值年CAGR与当前预测年→远期年CAGR后裁量的增速（百分数）
复合 PEG 对应 PE = 复合 PEG 系数 × 复合增速
复合 PEG 市值 = 主估值年度利润锚 × 对应 PE
```

它约束单年高增长外推。起止年份、实际/预测口径必须写清楚，不得混用。

### Forward PE

```text
Forward PE 市值 = 主估值年度利润锚 × Forward PE 区间
当前 Forward PE = 当前市值 / 同年度利润锚
```

Forward PE 区间至少由以下两类证据支持：公司历史估值分位、可比公司、增长持续性、ROIC/现金流质量、行业周期与竞争壁垒。不得从 PEG 结果反推一个 PE 后再把它当作“独立”验证。

## 6. Triangulation

每个情景分别形成三套候选区间：

| 情景 | 动态 PEG 区间 | 复合 PEG 区间 | Forward PE 区间 | 三锚结论 |
| --- | ---: | ---: | ---: | ---: |
| 正常 |  |  |  |  |
| 乐观 |  |  |  |  |

按以下顺序处理：

1. 优先取三者共同重叠区。
2. 若只有两者重叠，以两者重叠区为暂定区间，并明确第三锚为何偏离及需要什么证据消除分歧。
3. 若三者互不重叠，不给单点“精确目标”；输出冲突区间、最低共同假设和低置信度结论。
4. 不对三个市值结果做机械平均。
5. 动态 PEG 推导 PE 明显高于 Forward PE 上沿时，除非出现可验证的盈利持续性、稀缺性和现金流质量提升，否则以 Forward PE 为上限。
6. 复合 PEG 明显低于动态 PEG 时，优先判断是否存在低基数、周期高点或增长快速降速，不能自动选择更高者。

## 7. Valuation-Year Discipline

当前年份为 2026 年时：

- 正常/乐观主表使用 2027E 利润锚。
- 2028E 只列为估值年份切换情景。
- 只有 2027E 盈利高度可见，且新增证据证明市场已开始稳定资本化 2028E，才允许切换。
- 年份切换必须单独显示其贡献，不能伪装成 PEG 或 PE 上修。

## 8. Model-Discretion Catalyst Overlay

三锚先确定正常与乐观边界，模型再对催化剂作非机械裁量，输出当前状态估值。不得使用固定权重、固定加成、总分阈值或线性插值公式替代判断。

### Required Judgment

逐项综合而非机械计分：

| 维度 | 模型需要判断的问题 |
| --- | --- |
| 方向 | 对收入、利润率、现金流、增长持续性和估值偏好是正面还是负面？ |
| 强度 | 只是边际改善，还是足以改变利润锚、倍数或估值年份？ |
| 阶段 | 处于早期线索、经营验证还是财务兑现？ |
| 持续性 | 一次性扰动、季度延续还是中期结构变化？ |
| 独特性 | 公司相对竞争者是否真正获得额外收益？ |
| 计价程度 | 当前市场尚未计价、部分计价还是充分计价？ |
| 反证 | 哪条相反证据最可能使判断失效？ |

必须输出：

```text
催化剂综合方向：
模型判断的当前估值状态：正常 / 正常偏上 / 向乐观迁移 / 乐观 / 乐观充分定价
催化剂裁量后的当前合理估值区间：
相对正常/乐观边界的位置及理由：
判断置信度：低 / 中 / 高
最关键的升级证据与证伪信号：
```

当前合理估值区间由模型根据证据整体判断，不要求对应某个固定“兑现百分比”。可以偏向任一边界，也可以在证据相互抵消时维持正常区间。

### Three Transmission Channels

催化剂可通过三条通道进入估值：

| 通道 | 允许修改 | 必须看到的证据 |
| --- | --- | --- |
| 盈利锚修订 | 正常/乐观利润预测 | ASP、销量、产品结构、毛利率、订单或公司指引落入财务结果 |
| 倍数修订 | PEG 系数或 Forward PE | 增长持续性、现金流质量、竞争壁垒或稀缺性改善 |
| 年份切换 | 2027E -> 2028E | 近端盈利已验证且远期订单/产能/客户能见度充分 |

另有一类情况是领先证据尚未进入正式预测：模型可以在原正常/乐观边界之间给出裁量区间，提前反映情景迁移，但不得因此重写利润锚或突破乐观边界。

若催化剂已完整进入利润锚，不得以相同理由再次完整提高倍数。只有该证据同时改善增长持续性、现金流、竞争壁垒或稀缺性，才允许利润锚和倍数同时变化，并分别解释。

原材料涨价本身不直接上修估值。先判断：

```text
成本挤压：无法传导 -> 下修盈利或倍数
涨价传导：客户接受且毛利率稳定 -> 乐观情景概率上升
稀缺溢价：ASP/份额/结构/利润率改善 -> 先修订盈利；质量验证后再考虑倍数
```

## 9. Ex-Ante Replay and Revision Attribution

复盘历史估值时，保留原始版本并建立迁移表：

| 版本 | 估值日期 | 正常区间 | 乐观区间 | 当时利润锚/倍数 | 后续状态 |
| --- | --- | ---: | ---: | --- | --- |
| 原始事前估值 |  |  |  |  | 区间兑现或未兑现 |
| 新信息后估值 |  |  |  |  | 新估值，不回写旧版 |

市值变化拆为：

```text
目标市值变化
= 利润锚修订贡献
+ PEG / Forward PE 倍数修订贡献
+ 估值年份切换贡献
+ 催化剂裁量导致的区间内迁移
+ 交互项
```

明确回答：这是原乐观情景兑现，还是新信息使整个估值框架上移。价格到达原乐观区间不能单独证明应上修新区间。

## 10. Sanity Checks

- 检查市值单位、利润单位、股本与复权口径。
- 目标价必须等于目标市值除以最新总股本。
- 同时展示目标市值对应的 2027E Forward PE，防止 PEG 公式产生异常高倍数。
- 对高增长检查基数、非经常损益、少数股东损益、投资收益及现金流。
- 检查最近实际年度是否进入增长全景；若未展示，估值不完整。
- 检查估值增速与PEG系数是否因同一项盈利跃迁或催化剂同时上调。
- 展示0.9/1.0/1.1 PEG敏感性，并明确最终采用哪一档、为什么。
- 乐观区间必须有比正常区间更严格的触发条件，不能只换一个更高 PEG。
- 当前股价已经处于乐观区间时，报告应写“乐观情景已定价/接近充分定价”，不能把乐观区间重命名为正常区间。
