# Catalyst Validation Reference

用于 `equity-catalyst-tracker` 的历史基准率、反事实和时间兑现。它不是另一套选股规则，而是把“可能有催化”变成可审计、可跟踪的验证对象。

## 1. 历史基准率卡片

每个事件只建立一个明确的事件定义和一个主要成功定义：

```text
事件类型：客户认证转量产 / 提价 / 订单加急 / 扩产投产 / 技术路线确认 / ...
事件时点：YYYY-MM-DD；信息可得时间不能晚于事件时点
可比样本：相同产业环节、相近公司规模/周期位置/事件强度
观察窗口：例如 1/2/4 个季度，或线索后 60/120/240 个交易日
成功定义：订单转收入、收入增速上修、毛利率改善、OCF改善、估值锚迁移中的一个主指标
成功数 / 总样本：n_success / n_total
成功率 / 失败率：仅在样本定义一致时计算
来源：逐条列出公告、财报、客户/供应商或原始数据
偏差：选择偏差、幸存者偏差、回填偏差、定义漂移、信息不可得
```

规则：

- 样本少于 5 个，或成功定义无法统一时，不输出精确成功率，只写“基准率不足”，给出样本列表和方向性判断。
- 同一公司同一轮事件不得重复计数；事件发生后才知道的结果不能用于构造事件样本。
- 股价上涨只能作为定价结果，不是基本面成功的替代定义；若同时报告价格成功率，必须单独命名。
- 基准率应优先使用公司自身历史、同行历史和同一行业周期样本；混合样本要说明权重和可比性。

## 2. 反事实卡片

至少写出三条对照路径：

```text
公司特有冲击：公司暴露度、传导权、增量订单/ASP/份额/利润率证据
行业共同变化：同行、行业价格、供需、客户 capex 是否同步
市场整体 beta：指数、风格、流动性、汇率或风险偏好贡献
无事件替代路径：若没有该事件，原来的趋势是否仍可由旧驱动解释
```

优先级从强到弱：同日/同期同行对照 > 行业指数对照 > 市场指数对照 > 纯叙事比较。若公司和同行同涨、但相对行业没有超额，催化更可能是行业 beta；若公司在事件后相对同行出现可持续超额，才支持公司特有冲击。反事实不能证明因果，但可以防止把共振误写成单点催化。

## 3. 时间兑现卡片

为每个催化建立阶段表：

| 阶段 | 典型窗口 | 必须验证 | 失效/过期条件 |
| --- | --- | --- | --- |
| 线索期 | 0–30天 | 客户/供应商/渠道信号、管理层口径 | 无二次来源或信息被否认 |
| 验证期 | 15–90天 | 样品、认证、排产、交期、价格 | 无进展、推迟或需求反转 |
| 订单期 | 30–180天 | 合同、锁单、预付款、订单排产 | 订单取消、未交付 |
| 收入确认期 | 1–4个季度 | 出货、验收、收入结构 | 只有合同负债/存货，没有收入 |
| 利润兑现期 | 2–6个季度 | ASP、毛利率、费用率、现金流 | 利润率未改善或现金流恶化 |
| 估值迁移期 | 与预期修正同步 | 一致预期、目标估值锚、相对行业定价 | 股价/估值先透支，预期不再上修 |

窗口不是承诺。输出时同时记录“预期滞后”和“实际进度”；延迟必须归因于认证、客户导入、产能、交付、会计确认或需求变化之一。过期催化不能因为股价仍强而自动续期。

## 4. 缺失数据时的降级

- 无足够历史样本：降为机制判断，写明样本数和不可比原因。
- 无同行或指数对照：不能声称公司特有，只能写“公司与行业共同变化尚未拆分”。
- 无时间窗或验证指标：不能写“即将兑现”，只能写“待跟踪”。
- 只有市场解读、没有原始证据：证据等级不高于 2，不能升级为已兑现。
- 反事实结果与主线冲突：保留冲突，降低因果置信度，不用叙事强行消除。
