# 日线模型口径

| 因子 | 触发口径 |
|---|---|
| 拥挤脆弱 | 仅用点时中证全指成分。T-1 的 60 日 Beta 前 20%、Beta>1、20 日跑赢全指且在 MA20 上方定义既有龙头；T 日全指上涨并距 20 日高点不超过 3%，龙头贡献为正、非龙头贡献为负、估算总贡献为正，市场及非龙头上涨比例均低于 50%。原始触发后黄灯保持 7 个交易日。 |
| 领导瓦解 | 半导体 AI 链五指数等权高 Beta 复合指数：创业板、申万半导体、中证半导体产业、中证人工智能、中证通信设备各占20%；从 20 日高点回撤低于 -10%，且五日相对沪深300低于 -3%。 |
| 广度衰减 | 全市场当日上涨比例低于 50%，且相对前两个交易日较高值下降超过 25 个百分点。 |
| 流动性压缩 | 全市场成交额连续 4 次下降且四日累计下降至少 20%，同时中证全指低于 MA10、四日收益为负、上涨家数广度继续走弱。 |
| 跨指数共振 | 沪深300、中证500、中证1000、创业板中至少两个指数的当日收益低于仅用 T-1 及以前数据估计的 60 日波动率 -1.5σ。 |
| 海外冲击 | 严格早于 A 股信号日的最近美股交易日，IXIC 或 SOX 跌幅不高于 -2.5%，且国内高 Beta 复合指数五日跑输沪深300。 |

## 仓位

```text
五股等权组合20日实现波动率 = std(日收益) × sqrt(252)
波动率目标仓位 = min(100%, 18% / 实现波动率)
次日开盘目标总仓位 = 波动率目标仓位 × 状态乘数
状态乘数：0=100%、1=100%、2=75%、3=50%、4=35%、5=20%、6=0%
```

状态乘数中的 2/4/5 分是插值。该模型识别“不值得满仓承担风险的状态”，不是预测次日必跌。

## 数据和未来函数约束

- 龙头身份在 T-1 固定，T 日只测贡献。
- 历史指数成分权重只使用不晚于信号日的最近快照。
- 跨指数滚动波动率不包含 T 日。
- 次晨报告使用不晚于 A 股 T 日的最近完整美股交易日；同日期美股收盘在中国次晨已经完成，因此可纳入。
- 日线结果于 T 日收盘后生成，只能在 T+1 开盘执行。
- 五个领导篮子成分必须全部覆盖至 T 日；任一成分缺失时不得生成 T 日完整信号。四个行业/主题指数统一从 `/Users/a/khquant/data/simon_style_indices.db` 读取，其中申万半导体可在历史日线归档前使用官方收盘后实时快照。
- 新增日行情若账号无 `stock_st` 权限，用查询当日 `stock_basic.name` 中的 `ST/*ST` 标记排除风险警示股；已审计历史样本不受此回退影响。
