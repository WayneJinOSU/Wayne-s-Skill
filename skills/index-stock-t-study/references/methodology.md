# 指数压力位—个股日内事件研究方法

## 1. 研究问题

本技能研究的是一个可证伪的事件问题：

> 当沪指或其他指数在已知价格位发生首次有效触碰后，指定权重股在未来5/15/30分钟和当日剩余时间内，是否出现稳定的回撤、收盘修复，且这种路径是否相对同钟点普通行情有增量解释力？

它不是预测每一次最高点，也不是证明事后最低点可被提前知道。若用户提出“指导做T”，先把问题拆成事件反应、相对基线和执行可行性三层。

## 2. 上游因子与无前视

### 江恩

从 `gann-space-resonance` 读取已经冻结的候选区间、独立来源数、锚点日期、确认日期、触碰容差和失效说明。不能在看到个股响应后重新选择成员或扩大区间。

### 斐波那契/黄金分割

以目标日前已经确认的波段高点与低点计算。对下降段，常见回撤位为：

```text
level = low + (high - low) * ratio
ratio ∈ {0.236, 0.382, 0.500, 0.618, 0.786}
```

对上升段，若研究回踩支撑，方向要反向表述并保留原始高低点。必须同时保存：波段起止日期、价格、当时是否已确认、计算日期和比例。例：`3741.11 → 4175.35` 得到的压力参考位约为 `3843.59 / 3906.99 / 3958.23 / 4009.47 / 4082.42`，只是方法示例，不是永久固定的交易位。

### MA120

MA120只能使用目标事件发生前已完成的日线收盘数据。若分钟级研究把日线MA120映射到盘中，要说明采用前一交易日已知值还是当日收盘后重算值；默认采用前一交易日值，禁止把当日收盘纳入盘中信号。

## 3. 事件定义

### 压力

对每个因子和交易日，从指数5分钟序列中找最早满足以下条件的K线：

- 上一根收盘或本根开盘位于压力位下方（允许冻结的容差）；
- 本根高点触及或越过压力位；
- 事件时间为本根5分钟K线收盘时，而非本根内的最高价时刻。

若指数开盘即在压力位上方，应单独标为 `gap_above`，不要和从下方首次触碰混合。若同一交易日多次触碰，默认只保留首次有效事件；研究重复触碰时必须明确事件间隔和去重规则。

### 支撑

将方向反转：上一根在支撑位上方，本根低点触及或跌破支撑位，信号同样在本根收盘后生效。

### 容差

容差在研究开始前冻结，可以用百分比（例如±0.1%）或点数。不要为不同因子事后选择不同容差以提高命中率；若必须探索多个容差，要报告多重尝试并降级结论。

## 4. 个股参考价和窗口

事件时刻之后，选择第一根完整可用的个股5分钟K线：

- `next_open`：默认参考价，模拟触碰K线收盘后才可执行；
- `next_close`：用于核对第一根响应，但不能替代可执行参考价；
- 若指数和个股没有同步交易时间，记录对齐偏差秒数/分钟数。

压力事件至少计算：

- `future_5m_low`、`future_15m_low`、`future_30m_low`；
- 触碰后至收盘的最低价、时间和相对 `next_open` 的跌幅；
- 触碰后当日收盘价及相对 `next_open` 的涨跌幅；
- 最低价到收盘的修复幅度。

支撑事件对称计算未来高点和收盘表现。午休、停牌、涨跌停、缺失K线和当天没有后续完整窗口时，必须有单独状态字段，不得静默填零。

## 5. 对照与统计

优先使用同股票、同交易时段、同钟点、非事件日对照。若市场状态可得，可再按指数方向、波动率或日线趋势分层。每张汇总表至少包含：

- 事件数和覆盖率；
- 均值、中位数、P25/P75或其他分位数；
- 回撤阈值命中率（如≥0.5%、≥1.0%、≥1.5%）；
- 对照样本同口径统计；
- 事件减对照的百分点差和置信区间/自助法区间（样本允许时）；
- 缺失窗口数量和排除规则。

可用的增量表达：

```text
event_excess = event_mean_return - matched_control_mean_return
```

不要把事件均值本身误写成压力位的因果效果。样本很小时，优先展示逐事件明细、分布和反例，少做显著性断言。

## 6. 结论等级

建议按以下语言分级：

1. **未覆盖**：样本期没有真实触碰；不能判定有效或无效。
2. **案例反应**：有少量事件，触碰后出现回撤/修复，但缺少对照或样本太少。
3. **探索性有效**：多个事件方向较一致，且相对同钟点对照有一定增量；仍需扩样。
4. **初步可复现**：独立时间段、不同股票或滚动样本均出现类似增量，且执行口径冻结。
5. **策略待回测**：只有在明确库存、手续费、滑点、涨跌停、T+1和退出规则后，才可另行进行策略回测；事件研究本身不等于这一层。

## 7. 江恩与斐波那契的分工

- 江恩共振优先作为指数时空触发器和候选排序器；
- 斐波那契/黄金分割优先作为回撤层级、幅度和压力带参照；
- MA120优先作为趋势背景或慢速边界；
- 因子重叠只提出“联合事件可能更强”的假设，必须用独立样本验证，不能把多个标签简单相加。
